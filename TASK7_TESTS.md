# Задание 7: Генерация unit-тестов

## Подход к тестированию

Для обеспечения качества кода были написаны тесты для следующих компонентов:

### 1. Тесты эндпоинтов (`tests/test_api.py`)
- Проверка корневого эндпоинта `/`
- Проверка доступности документации `/docs`
- Проверка регистрации пользователя `/auth/register`
- Проверка логина `/auth/login`

### 2. Тесты книг (`tests/test_books.py`)
- Проверка получения списка книг `/books/`
- Проверка получения несуществующей книги (404)

### 3. Тест здоровья (`tests/test_health.py`)
- Проверка работы приложения

## Покрытие тестами

Тесты покрывают базовую функциональность API. Для полного покрытия (90%+) требуется дополнительная работа:
- Тесты с JWT-токенами для защищённых эндпоинтов
- Тесты CRUD операций (создание, обновление, удаление)
- Тесты выдачи и возврата книг
- Тесты штрафов
- Тесты отчётов
- Граничные случаи

## Запуск тестов
pip install pytest httpx
pytest tests/ -v
