## Описание проекта
Веб-приложение для управления библиотекой:
- Книги (CRUD)
- Читатели (CRUD)
- Выдача и возврат книг
- Штрафы за просрочку
- Поиск и отчёты
- Аутентификация (JWT)
- Админ-панель

## Технологии
- Python 3.11+
- FastAPI
- SQLAlchemy
- PostgreSQL (SQLite для разработки)
- Alembic (миграции)
- Pytest (тесты)
- Docker, Docker Compose
- GitHub Actions (CI/CD)

## Сборка и запуск

### Локально
pip install -r requirements.txt
uvicorn app.main:app --reload

### Docker
docker-compose up --build
