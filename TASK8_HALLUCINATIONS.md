# Задание 8: Исправление галлюцинаций ИИ

## Что такое галлюцинация ИИ?

Галлюцинация — когда ИИ генерирует уверенный, но **неправильный** или **вымышленный** ответ. Например, предлагает несуществующую библиотеку, выдумывает API, использует неправильные типы данных.

## Пример галлюцинации

При генерации кода для библиотеки ИИ предложил:

from app.database import NonExistentClass  # ❌ Такого класса нет!
Как распознать
Проверить импорты — существует ли модуль/класс?

Запустить код — есть ли ошибка?

Сравнить с реальностью — соответствует ли предметной области?

Как исправил

from app.database import get_db  # ✅ Существующий импорт
Как изменить промпт
❌ Плохой промпт:

Напиши код для библиотеки
✅ Хороший промпт:

Ты — senior Python разработчик. Используя FastAPI и SQLAlchemy, создай CRUD для книг.
Модель Book уже существует в app/models.py. Не используй вымышленные классы.
Вывод
Галлюцинации ИИ — серьёзная проблема. Лучшие способы защиты:

Всегда проверять импорты

Запускать код после генерации

Уточнять в промпте: "используй только существующие модули"
